# 私信多模态能力

2026-10-10 功能调整：已移除「Agent 可用素材」卡片、上传/列出/移除接口及后台素材库挑选。模型只读取当前消息和最近聊天里的图片；历史文件保留以供聊天记录预览。下述素材库相关内容为移除前的实现和验证记录。

工作台沿用家庭网络出口。支持一对一文字（含颜文字、Unicode emoji）、图片（type 2）、原生大表情（type 13）、自定义表情包（type 16）；type 7 也按有图地址的原生表情数据解析。语音、视频和卡片显示类型占位，不作为本次媒体回复触发源。

收信、双方历史和断线补收共用内容解析器。原始媒体元数据保存在账号隔离的素材表中，聊天记录引用稳定 asset_id。私信图片通过登录鉴权接口预览，实际文件在 `.local/dm-media`，不使用公开文件目录。下载仅允许已确认的小红书 CDN 域名，禁止跳转，不携带平台登录 Cookie；最大 8MB，校验实际图像格式和像素尺寸。

模型每轮最多读取 8 份图像，当前消息优先，结合最近聊天和账号素材库。真实图像通过 Channel / Multica 附件传入；GIF 等动画抽取首、中、末帧，工作台预览保留原动画。历史中未附图的图片不可猜测。素材库可上传、移出；移出不破坏历史及已提交快照。

返回旧版 reply_text 仍可发文字；reply_message 支持 text、kaomoji、Unicode emoji 的 text，或 image、sticker、原生 emoji 的 asset_id。asset_id 必须来自本轮已读取的 catalog，且属于执行账号。一次只发送一条消息。上传文件经官方 IM upload permit、ROS 上传、CDN 转换后，用原生 IM 类型发送。发送前持久化素材、消息 ID 及意图；成功需匹配 ACK，结果不确定时暂停该会话，不自动重发。

2026-10-10 验证：211 项后端全量测试通过；最后增补后 78 项私信/网络检查通过；前端构建、桌面和 390px 手机预览通过，历史中 7 张图片均返回 200 并成功显示。合成视觉任务正确识别红色正方形和蓝色圆形。真实账号通过家庭网络发送文字（含 emoji 和颜文字）、图片、type 16 表情包和 type 13 大表情，四条均有匹配成功回执，用户确认四种在接收方手机均可见。私有验证记录保存在 `.local/dm-media-verification.json`、`.local/dm-media-model-smoke.json` 和 `.local/dm-media-send-smoke.json`。

## 自然图文回复与节奏（2026-10-10）

新协议使用 `reply_messages`：reply 时1至4条最终消息，no_reply 时空数组。每条使用现有 text/kaomoji/emoji/sticker/image 类型，并带0至15秒 `delay_seconds`。支持文字与媒体按任意顺序混合，不把多条当成候选答案。旧单条 `reply_message` / `reply_text` 的 API 输入仍受支持。

整个计划先校验后发送，每个气泡单独持久化发送意图、mid、匹配ACK及历史；下一条只有前一条成功才进入等待间隔。新入站、本人接话、模式变化或过期取消未发部分；发送不确定或拒绝会停止后续，重启保留不确定状态，不能重新分析已部分发送的计划以重放前文。批准模式一次批准整个计划，间隔期间继续检查账号开关和新活动；两秒合并窗口减少连续短消息触发多轮问答。记录页显示整组消息及各自状态。

素材检索优先保留当前图片，结合近期聊天、标签语义与最近使用情况，从账号素材库选取本轮最多8份实际视觉附件。两个绑定账号分别导入12张人工检查过的公开Tenor猫猫反应GIF；来源和审阅清单位于私有 `.local/reaction-pack`。可使用 `deploy/seed_dm_reactions.py` 收集候选，审阅后以 `reviewed.json` 显式导入指定账号；此脚本不发送任何私信。

主要现成技能改用 Peter Steinberger 的 gifgrep（SkillHub 1.0.1，查询时21117次下载、3103次安装）；CLI固定0.4.4并校验官方SHA256。其当前联网搜索需要GIPHY/KLIPY凭据，本机未配置；本地预览和现有账号素材回复已经可用。gifgrep、xhs-natural-expression 均挂载到原代聊agent，原模型设置保留。
